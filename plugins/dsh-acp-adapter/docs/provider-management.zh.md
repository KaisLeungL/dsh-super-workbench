# Provider 实例管理

本次改造沿用 ACP 后端，实例仍保存在 `agents[id]`，路由仍是 `acp-<id>`。

## 界面约定

- 入口位于「设置 → Agent Provider」，默认打开接入管理，另有会话总览。沿用 DSH 设置页的标题、说明和下划线标签栏；搜索框下显示简洁实例列表，详情在下方展开，窄屏单列。
- 添加依次选择类型、填写实例信息、配置运行时和环境，再保存并检查。目录来自随插件打包的 ACP Registry 快照，不能显示成在线安装服务。
- 详情依次显示状态、显示名、运行时、环境和模型信息。命令与参数默认折叠，通用 ACP 首次配置时展开。窄屏上下排列，不横向溢出。
- 稳定 ID 创建后只读；更改显示名不改变历史路由。删除显式确认并提示已绑定会话数量。
- 协议连通与登录信息独立。探针成功只显示“协议可用”；认证无可验证来源时显示“认证未知”，需要登录的失败显示 CLI 登录指引。

## 执行与兼容

`enabled` 缺席默认启用。停用后隐藏模型目录、拒绝后续调用及新派单；保留实例、已绑定会话、活动记录和内部路由，已经接受的调用继续完成。重新启用不改变启动指纹或历史绑定。

同类型实例各自拥有配置、路由、适配器、探针缓存和会话运行时。类型只选择已有运行时专化，不充当单例键。登录文件仍由 CLI 管理：默认目录可能共享账号；只有用户明确配置各自的 `CODEX_HOME`、`HOME` 或相应 CLI 支持的目录后才形成文件隔离，不自动迁移凭据。

普通 ACP 接入继续由外部 CLI 管理登录。新增的 **Codex · ChatGPT 托管授权** 使用 OpenAI 的 Sign in with ChatGPT（SIWC）直接授权路径，凭据由本插件管理，不覆盖原 CLI 登录。

## Codex 的 ChatGPT 托管授权

1. 从「设置 → Agent Provider → 接入管理 → 添加 Provider」选择「Codex · ChatGPT 托管授权」，填写名称并保存。
2. 详情中点击 **Continue with ChatGPT**，在系统浏览器核对账号并完成套餐使用授权。授权页和授权范围由 OpenAI 提供。
3. 返回 DSH 后，插件验证身份签名、issuer、audience、nonce 和授权范围，再保存非秘密的账号绑定并检查模型。仅完成身份登录但没有套餐使用权限时，会要求重新授权。
4. 选择该实例的模型即可新建对话或分派任务。原有 ACP 实例和旧会话保留原路由，继续使用原登录。

授权采用动态客户端注册、PKCE S256、随机 state 和本地回调。访问令牌与轮换刷新令牌只保存在 Host 的独立目录（目录 0700、文件 0600）；Provider 设置与历史指纹仅保存非秘密绑定。Codex 使用独立 `CODEX_HOME` 和私有本地令牌服务，按需获取令牌。该运行目录隔离认证和 Codex 会话数据，不是操作系统沙箱；工具权限仍由既有 DSH/ACP 链路负责。

令牌刷新串行执行，永久失效后清除令牌并提示重新授权。同实例绑定注册身份与用户 subject；其他账号应新建 Provider，避免旧会话静默切换账号。退出连接先尝试远端撤销，然后清除本地令牌并保留历史绑定；远端撤销未确认时明确显示。已经发出的推理请求不保证因撤销立即结束，停止执行仍使用 DSH 的取消按钮。通过详情删除托管实例时也先退出该连接。

本阶段不提供自动安装 CLI、跨账号迁移或在线 Registry 安装。托管实例默认沿用现有 Codex 命令，普通 ACP 配置不会自动转换。

官方依据：[SIWC 登录](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)、[身份与会话](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions)、[令牌参考](https://developers.openai.com/siwc/token-sharing-open-source/token-reference)、[Codex App Server 接入](https://developers.openai.com/siwc/token-sharing-open-source/codex-app-server)。模型目录或隔离协议测试不构成真实套餐调用验收。

## 验收

1. 旧配置缺省开关仍可读取；同类型多实例可保存、独立探测，修改一个实例不改变另一个实例配置或指纹。
2. 停用不终止已经接受的调用，不删除绑定；新调用被拒绝，重新启用后原路由恢复。
3. 真实 DSH Host 浏览器完成添加、校验、保存回读、编辑、启停、删除确认，验证秘密值不回显及窄屏布局。
4. 会话总览保留单会话实时详情与诊断；打开原生会话时关闭设置面板，原生团队派单、审批、取消和旧会话仍使用原链路。
