# 番茄时钟

DSH 左下角姓名上方的番茄钟入口。点击展开小悬浮窗，开启专注后入口显示“xx：xx 专注中”。

默认专注 25 分钟，短休息 5 分钟。支持暂停、继续、重置和收起；到时展示完成提示，下一阶段手动开始。计时以 Host 保存的结束时间为准，刷新、切换会话和多标签页共用同一状态。关闭 DSH 期间经过的时间在下次打开时计入。

通过 DSH `plugin_manager` 将本目录作为本地 bundle 安装。无需构建、运行新服务器或修改 DSH 应用文件。运行 `npm test` 验证状态转换、持久化顺序及 Host 路由与工具同步。

实现使用 `sidebar.footer.action` 和 `shell.overlay` 正式插槽、宿主主题 token 和中英文本地化。界面操作和 `pomodoro` 工具共用 Host 服务，数据写入 DSH JSON 存储的 `local_pomodoro` 单元。插件停用时清理计时器、流连接和事件监听。

专注和休息完成时，均展开完成提示；浏览器已获得通知权限时，同时发送桌面系统通知。首次点击开始或继续时请求通知权限，拒绝后仍保留页面提醒。使用浏览器锁与本地记录去重，避免多标签页、断线重连或刷新重复通知。页面关闭期间的通知依赖浏览器运行状态，下次打开时会显示尚未提醒的完成状态。

通知逻辑的源文件为 `completion-notifier.js`，修改后运行 `npm run build` 同步到独立的 Client 产物，再安装。分发文件已构建完成，安装不需要额外依赖。

图标为本项目原创 SVG，可随本插件使用。
